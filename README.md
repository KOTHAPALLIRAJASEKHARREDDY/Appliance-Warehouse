# Appliance-Warehouse

## 📌 Overview

Appliance-Warehouse is a full-stack web application developed as an academic project to simplify the process of buying and renting household appliances online. The platform allows customers to browse a variety of appliances, compare options, and choose whether to purchase or rent products based on their needs.

The application provides a seamless user experience through a responsive interface and secure backend functionality, making appliance shopping and rental management convenient and efficient.

## 🚀 Live Demo

🌐 https://appliance-warehouse.vercel.app/

---

## 🎯 Problem Statement

Purchasing household appliances can be expensive, especially for customers who only need them for a short period. Appliance-Warehouse addresses this challenge by providing a platform where users can either buy or rent appliances such as:

* Washing Machines
* Refrigerators
* Microwaves
* Air Conditioners
* Kitchen Appliances
* Other Household Appliances

This flexibility helps customers find cost-effective solutions based on their requirements.

## 🏗️ Application Architecture

The application follows a server-side rendered architecture using Flask and Jinja2 templates.

* HTML, CSS, and JavaScript are used to create the user interface.
* Flask handles routing, business logic, authentication, and request processing.
* Jinja2 templates dynamically render content on the server.
* MongoDB stores user accounts, appliance details, orders, and rental records.
* Vercel is used for deployment and hosting.

## ⚙️ Installation & Setup

### Prerequisites

Before running the project locally, ensure you have:

* Python 3.x
* MongoDB
* Git

### Clone the Repository

```bash
git clone https://github.com/your-username/Appliance-Warehouse.git
cd Appliance-Warehouse
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure MongoDB

Make sure MongoDB is installed and running on your machine.

Update the MongoDB connection string in the project configuration if necessary.

### Run the Application

```bash
python server_main.py
```

The application will start locally and can be accessed through your browser.
